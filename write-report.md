# Write Report

## Writing style

- Write short, clear sentences that go straight to the point.
- Keep each sentence focused on one main idea.
- Use direct language. Remove filler, repetition, and unnecessary detail.
- Do not use em dashes. Use periods, commas, or parentheses instead.

## Evidence

- Read the file or files provided for the report before drafting.
- Use only findings present in those files. Do not invent findings or add outside information.
- Preserve the reported values, units, group labels, comparison directions, and statistical results accurately.
- Do not claim statistical significance, biological mechanisms, or causal relationships unless the source supports those claims.
- If information is missing or unclear, state that briefly or ask for clarification. Do not fill gaps with assumptions.
- Do not present new calculations or analyses as findings from the file. Perform additional analysis only when the user requests it, and label it clearly.

## Final review

- Check every factual claim against the source files.
- Remove unsupported claims and unnecessary wording.
- Confirm that the report contains no em dashes.
